# 🍾 Bottle Spin Bot

Интерактивный парти-гейм на базе Telegram для встреч и игры в "Бутылку"!

## ✨ Особенности

### 🎮 Игровые Механики
- **Открытые Столы**: Список всех активных комнат
- **Быстрое Присоединение**: Присоединитесь к случайной комнате одним кликом
- **Мультиплеер**: До 12 игроков в одной комнате
- **Крутение Бутылки**: Случайное сопоставление игроков
- **Решения**: Поцеловать или пропустить (10 секунд на выбор)
- **Система Вознаграждений**: Монеты и популярность за поцелуи

### 👥 Социальные Функции
- **Профили Игроков**: Личная страница с статистикой
- **Таблица Лидеров**: Топ 10 по популярности
- **Система Подарков**: Отправляйте виртуальные подарки
- **Поиск Комнат**: Поиск по названию и языку

### 💎 VIP Система
- Выделенный профиль (✨)
- Доступ к элитным комнатам
- Бонус +20% к монетам
- 10 бесплатных подарков в день
- Без объявлений

### ⚡ Система Энергии
- Начальная энергия: 100
- Каждый спин стоит: 5 энергии
- Восстановление: 1 в минуту
- Полное восстановление: 10 ⭐

### 🎁 Система Подарков
- Розы, Тюльпаны, Вино, Пиво
- Торт, Шоколад, Кольцо, Сердце
- Звезда, Алмаз
- Каждый подарок +10 к популярности

## 🚀 Быстрый Старт

### Требования
- Python 3.10+
- PostgreSQL 13+
- Redis 6+

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/muratovjahongir19-lang/card-game-miniap.git
cd card-game-miniap/bottle_spin_bot

# Создаем виртуальную среду
python3 -m venv venv
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Копируем конфиг
cp .env.example .env

# Редактируем .env и добавляем TELEGRAM_BOT_TOKEN

# Запускаем бота
python bot/main.py
```

### Docker Compose

```bash
docker-compose up -d
```

## 🎮 Как Играть

1. **Присоединитесь к комнате**
   - Нажмите "Join Room" или "Random Room"
   - Подождите других игроков

2. **Крутение бутылки**
   - Бутылка вращается каждые 30 секунд
   - Вы сопоставляетесь с игроком противоположного пола

3. **Примите решение**
   - ❤️ Поцеловать
   - ❌ Пропустить
   - У вас есть 10 секунд!

4. **Получите награды**
   - Если оба выбрали поцелуй: +50 монет, +5 популярности
   - Если один пропустил: нет награды

5. **Отправляйте подарки**
   - Выберите подарок
   - Потратьте монеты
   - Получите +10 популярности

## 💰 Система Валют

### Монеты (💰)
- Получаются за поцелуи
- Тратятся на подарки
- 1000 монет = 50 ⭐

### Звезды (⭐)
- Покупаются в Telegram
- VIP подписка
- Восстановление энергии

- **Поцелуи**: Игроки с наибольшим количеством поцелуев

## 🐛 Решение проблем

### "Bot doesn't respond"
- Проверьте TELEGRAM_BOT_TOKEN
- Проверьте интернет соединение
- Посмотрите логи: `python bot/main.py`

### "Database connection error"
- Убедитесь PostgreSQL запущен
- Проверьте DATABASE_URL в .env
- Создайте БД: `createdb bottle_spin_bot`

### "Redis connection refused"
- Убедитесь Redis запущен
- Проверьте REDIS_URL в .env
- Проверьте: `redis-cli ping`
